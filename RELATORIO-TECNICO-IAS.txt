1. STACK REAL DO PROJETO
------------------------------------------------------------------------
Framework:        React 19 + TanStack Start (SSR) + TanStack Router (file-based)
Backend:          TanStack Start Server Functions (createServerFn) + Cloudflare Workers
Banco de dados:   Supabase (PostgreSQL)
WhatsApp:         Evolution API (Baileys) — QR Code, webhook, envio/recebimento
UI:               Tailwind CSS 4 + shadcn/ui (Radix) + Lucide Icons + Recharts
State:            TanStack Query (server state) + useState local
Auth:             Supabase Auth (email/password) + tabela profiles + user_roles
Build/Deploy:     Vite 7 + @lovable.dev/vite-tanstack-config + Cloudflare Workers
Origem:           Projeto gerado via Lovable.dev
